# 24. YOLOv11 환경 구축

## 개요
Ultralytics YOLOv11 환경을 구축합니다.

## 설치
`ash
pip install ultralytics
`

또는 저장소 클론:
`ash
git clone https://github.com/ultralytics/ultralytics
cd ultralytics
pip install -e .
`

## 확인
`ash
yolo version
`

## Jetson 최적화
TensorRT 사용을 고려합니다.
